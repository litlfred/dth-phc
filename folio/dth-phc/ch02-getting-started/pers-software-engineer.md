# Software engineer

A core member of the PCPOSS implementing team or technology partner (section 2.2) who builds, configures, integrates and tests the PCPOSS software:

- **Role definition (section 2.2):** *"A technical expert who creates and adapts software solutions. Sometimes referred to as a developer."*
- **Phase 2 — Design and adaptation (Chapter 4, `sec-020`, `sec-024`):** Builds and configures the PCPOSS increment (MVP, Version 1, Version 2) and executes the 7-part QA test suite in section 4.5 (unit tests, integration tests, functional tests, performance tests, security tests, usability tests and compatibility tests).
- **Phase 3 — Training, testing and roll-out (Chapter 5, `sec-025`, `sec-027`):** Supports technical maintenance training (5.1.2), resolves defects found during User Acceptance Testing (5.2), and supports production deployment and ongoing maintenance (5.3, 5.4).
