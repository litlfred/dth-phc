# Monitoring and evaluation (M&E) specialist

A specialist Named in the Phase 1 (`sec-011`) and Phase 4 (`sec-029`) "Who should be involved" panels who defines aggregate health indicators and monitors PCPOSS implementation performance and scale-up readiness:

- **Phase 1 — Understanding user requirements (Chapter 3, `sec-011`, `sec-015`):** Maps national and programme aggregate indicators (HMIS / DHIS2 reporting indicators) to individual-level PCPOSS data elements (3.4.3, Annex 9) so routine reporting is generated automatically from point-of-service care without duplicate tally sheets.
- **Phase 4 — Scale-up (Chapter 6, `sec-029`–`sec-031`):** Conducts the scale-up readiness assessment (6.1), defines SMART objectives and Table 5 benchmarks (6.2), and monitors implementation progress against targets (6.3) feeding the `ready-to-scale-up.dmn` gateway.
